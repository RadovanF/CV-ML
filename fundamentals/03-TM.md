# Template Matching v počítačovém vidění

## Co je Template Matching?

Template matching (TM) je základní technika pro lokalizaci vzorového obrázku (template) uvnitř většího cílového obrázku. Principem je posouvání šablony přes cílový obrázek a výpočet skóre podobnosti v každé pozici.

**Klíčové vlastnosti:**
- Vyžaduje zdrojový obrázek (input) a šablonu (template).
- Porovnává šablonu s překrývajícími se regiony obrazu.
- Výsledkem je matice, kde každá hodnota indikuje míru podobnosti.

### Možné aplikace
- **Detekce objektů**: Identifikace objektů hledáním oblastí odpovídajících šabloně.
- **Rozpoznávání obličejů**: V bezpečnostních systémech.
- **Navigace robotů**: Rozpoznávání orientačních bodů.
- **Kontrola kvality**: Inspekce defektů porovnáním se standardem.
- **Lékařské zobrazování**: Identifikace anatomických struktur.

## Metody porovnávání v OpenCV

OpenCV implementuje několik metod pro výpočet podobnosti (`cv2.matchTemplate`), které vrací matici výsledků.

### Základní metody
1. **SAD (Sum of Absolute Differences)**: Součet absolutních rozdílů.
2. **SSD (Sum of Square Differences)**: Součet čtverců rozdílů - metoda `TM_SQDIFF`.
   - Nejlepší shoda je globální minimum.
3. **CC (Cross Correlation)**: Křížová korelace - metoda `TM_CCORR`.
   - Nejlepší shoda je globální maximum.
   - **Omezení**: Výsledek silně závisí na jasu a kontrastu. Světlá oblast dá vysokou korelaci, i když neodpovídá vzoru.
4. **Correlation Coefficient**: Korelační koeficient - metoda `TM_CCOEFF`.
   - Porovnává šablonu relativně k jejímu průměru. 1 = perfektní shoda, -1 = neshoda.

### Normalizované metody (Doporučené)
Normalizované verze do určité míry řeší problémy s různým osvětlením škálováním výsledků do konzistentního rozsahu (např. 0 až 1).

- `TM_SQDIFF_NORMED`: Hledáme minimum (nejlepší shoda blízká 0).
- `TM_CCORR_NORMED`: Hledáme maximum (nejlepší shoda blízká 1).
- `TM_CCOEFF_NORMED`: Hledáme maximum (nejlepší shoda blízká 1).

#### Ukázka výpočtu (Příklad)

Pro lepší pochopení rozdílů mezi metodami si ukážeme výpočet na jednoduchých 1D příkladech.

**Společná šablona ($T$):** `[0, 30, 0]` (Tmavý objekt "kopec" od nulové základny)

#### 1. TM_SQDIFF (Klasický rozdíl) – příklad se změnou kontrastu
**Obraz ($I$):** `[0, 60, 0]` (Stejný tvar, ale dvojnásobný kontrast – násobení ×2)

$$R = \sum (T - I)^2 = (0-0)^2 + (30-60)^2 + (0-0)^2 = 0 + 900 + 0 = 900$$

**Závěr:** Velká chyba (900). Bez normalizace je metoda velmi citlivá na změny kontrastu.

#### 2. TM_SQDIFF_NORMED (Normalizovaný rozdíl)
Stejný příklad se změnou kontrastu:

$$R = \frac{\sum (T - I)^2}{\sqrt{\sum T^2 \cdot \sum I^2}}$$

* Čitatel: 900 (z bodu 1)
* $\sum T^2 = 0^2 + 30^2 + 0^2 = 900$
* $\sum I^2 = 0^2 + 60^2 + 0^2 = 3600$
* Jmenovatel: $\sqrt{900 \cdot 3600} = \sqrt{3\,240\,000} = 1800$

**Výsledek: 900 / 1800 = 0,5**

**Závěr:** Je to zlepšení oproti nenormalizované verzi (z 900 na 0,5), ale pořád to není ideální shoda. 0,5 je spíš „střední“ výsledek – metoda změnu kontrastu zmírnila, ale nezcela eliminovala.

#### 3. TM_CCOEFF_NORMED (Normalizovaný korelační koeficient) – příklad se změnou kontrastu
Stejný příklad (dvojnásobný kontrast):

$$R = \frac{\sum (T' \cdot I')}{\sqrt{\sum T'^2 \cdot \sum I'^2}}$$

kde $T' = T - \bar{T}$ a $I' = I - \bar{I}$ (odečtení průměru pro každý pixel).

**Krok 1: Výpočet průměrů**
- Průměr šablony: $\bar{T} = \frac{0 + 30 + 0}{3} = 10$
- Průměr obrazu: $\bar{I} = \frac{0 + 60 + 0}{3} = 20$

**Krok 2: Odečtení průměru (centrování)**
- $T'_1 = 0 - 10 = -10$
- $T'_2 = 30 - 10 = 20$
- $T'_3 = 0 - 10 = -10$

- $I'_1 = 0 - 20 = -20$
- $I'_2 = 60 - 20 = 40$
- $I'_3 = 0 - 20 = -20$

**Krok 3: Součin $T' \cdot I'$ pro každý pixel**
- Pixel 1: $(-10) \times (-20) = 200$
- Pixel 2: $20 \times 40 = 800$
- Pixel 3: $(-10) \times (-20) = 200$

**Čitatel (suma součinů):** $200 + 800 + 200 = 1200$

**Krok 4: Součet čtverců pro $ T' $**
- $(-10)^2 = 100$
- $20^2 = 400$
- $(-10)^2 = 100$

$\sum T'^2 = 100 + 400 + 100 = 600$

**Krok 5: Součet čtverců pro $ I' $**
- $(-20)^2 = 400$
- $40^2 = 1600$
- $(-20)^2 = 400$

$\sum I'^2 = 400 + 1600 + 400 = 2400$

**Krok 6: Jmenovatel**
$\sqrt{\sum T'^2 \cdot \sum I'^2} = \sqrt{600 \cdot 2400} = \sqrt{1\,440\,000} = 1200$

**Krok 7: Finální výsledek**
$$R = \frac{1200}{1200} = 1,0$$

**Přesně 1,0 (perfektní shoda).**

**Závěr:** I přes dvojnásobný kontrast vyjde výsledek přesně 1,0. Metoda je robustnější vůči multiplikativním změnám kontrastu (a také vůči additivnímu posunu jasu). Díky odečtení průměru a normalizaci se soustředí čistě na tvar vzoru – proto je `TM_CCOEFF_NORMED` obvykle preferovanou volbou pro většinu praktických případů.

## Template Matching ve scikit-image

Knihovna `scikit-image` nabízí funkci `match_template` v modulu `skimage.feature`. Používá rychlou normalizovanou křížovou korelaci.

## Omezení metod porovnávání se šablonou a alternativní přístupy

Metoda porovnávání se šablonou je z podstaty svého matematického aparátu charakterizována několika fundamentálními omezeními:

* **Absence měřítkové invariance:** Hledaný objekt je v cílovém obraze detekován pouze v případě, že jeho velikost exaktně odpovídá rozměrům poskytnuté šablony.
* **Absence rotační invariance:** Algoritmem nejsou zachyceny objekty, které jsou v cílovém obraze vůči šabloně úhlově natočeny.
* **Citlivost na perspektivní zkreslení a deformace:** Při změně úhlu snímání kamery nebo při tvarové deformaci objektu je míra shody degradována.
* **Nízká robustnost vůči zákrytům (Occlusion):** Pokud je hledaný objekt částečně zakryt jiným prvkem scény, hodnota korelačního koeficientu je snížena, čímž je vyvoláno selhání detekce.

Pro řešení těchto omezení je u komplexnějších úloh analýzy obrazu aplikován přechod k metodám, jimiž je úloha detekce řešena s vyšší mírou generalizace:

* **Lokalizace pomocí invariantních příznaků:** Pro úlohy s požadavkem na geometrickou invarianci jsou aplikovány detektory a deskriptory klíčových bodů (např. SIFT, SURF, ORB). Místo aby algoritmus porovnával celý obrázek pixel po pixelu, najde na šabloně i na prohledávané fotce výrazné body (typicky ostré rohy nebo výrazné hrany). Následně každému takovému bodu vytvoří matematický popis (tzv. deskriptor), který funguje jako jeho unikátní "otisk prstu". Nakonec vezme otisky ze šablony a hledá, jestli se ty samé otisky nenachází i na velké fotce. Díky tomu si s otočením nebo změnou velikosti poradí lépe než klasický Template Matching. Avšak při příliš velkém zakrytí nebo extrémním úhlu může i tato metoda selhat.
* **Metody strojového učení (Machine Learning):** Pro detekci specifických tříd objektů (např. detekce osob) jsou využívány klasifikátory pracující nad příznakovými vektory. Je využíván histogram orientovaných gradientů (HOG) ve spojení s algoritmem Support Vector Machine (SVM) nebo Haarovy kaskády.
* **Metody hlubokého učení (Deep Learning):** V aplikacích s požadavkem na generalizaci jsou nasazovány architektury konvolučních neuronových sítí (CNN), jako jsou detektory YOLO (You Only Look Once). Těmito modely je prováděna regrese ohraničujících rámečků a klasifikace v jednom výpočetním kroku. Natrénovanou sítí je dosaženo invariance vůči transformacím, změně osvětlení i částečným zákrytům. Pro proces trénování je vyžadována příprava anotovaného datasetu a pro inferenci je typicky alokován specializovaný hardware (GPU).

## Praktická ukázka výpočtu (Python)

Níže je uveden skript pro numerickou demonstraci 1D příkladů s následným ověřením prostřednictvím funkcí knihovny OpenCV.

```python
"""
Template Matching - Příklady z TM-01.md
========================================
Ruční výpočet 1D příkladů (TM_SQDIFF, TM_SQDIFF_NORMED, TM_CCOEFF_NORMED)
s ověřením pomocí OpenCV.

Společná šablona: T = [0, 30, 0]
Obraz:            I = [0, 60, 0]  (stejný tvar, dvojnásobný kontrast)
"""

import cv2
import numpy as np
import math

# Vstupní data
T = np.array([0, 30, 0], dtype=np.float64)
I = np.array([0, 60, 0], dtype=np.float64)

# Pro OpenCV – 1D data jako 1-řádkové obrázky
T_2d = T.reshape(1, -1).astype(np.float32)
I_2d = I.reshape(1, -1).astype(np.float32)

print(f"Šablona T: {T}")
print(f"Obraz   I: {I}")

# =============================================================================
# 1. TM_SQDIFF – Sum of Squared Differences
# =============================================================================
print(f"\n{'=' * 60}")
print("1. TM_SQDIFF - klasický rozdíl (citlivý na kontrast)")
print("=" * 60)

# R = sum( (T - I)^2 )
R_sqdiff = np.sum((T - I) ** 2)

print(f"R = sum((T - I)²)")
print(f"  = (0-0)² + (30-60)² + (0-0)²")
print(f"  = 0 + 900 + 0 = {R_sqdiff:.0f}")

# Ověření
cv_sqdiff = cv2.matchTemplate(I_2d, T_2d, cv2.TM_SQDIFF)
print(f"\nOpenCV ověření: {cv_sqdiff}")
print(f"Závěr: Velká chyba, metoda je citlivá na kontrast.")

# =============================================================================
# 2. TM_SQDIFF_NORMED - normalizovaný rozdíl
# =============================================================================
print(f"\n{'=' * 60}")
print("2. TM_SQDIFF_NORMED - normalizovaný rozdíl")
print("=" * 60)

# R = sum((T-I)²) / sqrt(sum(T²) * sum(I²))
citatel = np.sum((T - I) ** 2)           # = 900
sum_T2 = np.sum(T ** 2)                  # = 900
sum_I2 = np.sum(I ** 2)                  # = 3600
jmenovatel = math.sqrt(sum_T2 * sum_I2)  # = 1800

R_sqdiff_n = citatel / jmenovatel

print(f"R = sum((T-I)²) / sqrt(sum(T²) · sum(I²))")
print(f"  Čitatel:   {citatel:.0f}")
print(f"  sum(T²)  = {sum_T2:.0f}")
print(f"  sum(I²)  = {sum_I2:.0f}")
print(f"  Jmenovatel = sqrt({sum_T2:.0f} · {sum_I2:.0f}) = {jmenovatel:.0f}")
print(f"  R = {citatel:.0f} / {jmenovatel:.0f} = {R_sqdiff_n:.1f}")

# Ověření
cv_sqdiff_n = cv2.matchTemplate(I_2d, T_2d, cv2.TM_SQDIFF_NORMED)
print(f"\nOpenCV ověření: {cv_sqdiff_n}")
print(f"Závěr: Lepší (0.5), ale stále ne ideální – kontrast jen zmírněn.")

# =============================================================================
# 3. TM_CCOEFF_NORMED – normalizovaný korelační koeficient
# =============================================================================
print(f"\n{'=' * 60}")
print("3. TM_CCOEFF_NORMED - korelační koeficient")
print("=" * 60)

# Odečteme průměry (centrování)
T_c = T - np.mean(T)  # [-10, 20, -10]
I_c = I - np.mean(I)  # [-20, 40, -20]
print(f"T' = T - průměr(T) = {T_c}")
print(f"I' = I - průměr(I) = {I_c}")

# R = sum(T'·I') / sqrt(sum(T'²) · sum(I'²))
citatel = np.sum(T_c * I_c)
jmenovatel = math.sqrt(np.sum(T_c**2) * np.sum(I_c**2))
R_ccoeff_n = citatel / jmenovatel

print(f"\nR = sum(T'·I') / sqrt(sum(T'²) · sum(I'²))")
print(f"  = {citatel:.0f} / {jmenovatel:.0f} = {R_ccoeff_n:.1f}")
print(f">>> Perfektní shoda ({R_ccoeff_n:.1f}) i přes dvojnásobný kontrast! <<<")

# Ověření
cv_ccoeff_n = cv2.matchTemplate(I_2d, T_2d, cv2.TM_CCOEFF_NORMED)
print(f"\nOpenCV ověření: {cv_ccoeff_n}")
print(f"Závěr: TM_CCOEFF_NORMED je nejrobustnější - doporučená metoda.")
